## Troubleshooting

### If the workflow doesn't trigger:

1. Verify the tag was pushed: `git ls-remote --tags origin`
2. Check the workflow file for syntax errors
3. Check the Actions tab for any error messages

### If the workflow fails:

1. Click on the failed workflow run in the Actions tab
2. Check the logs for error messages
3. Common issues:
   - Submodules not initialized correctly
   - Build errors in the code
   - Permissions issues with GITHUB_TOKEN

### If the .zip file is not uploaded:

1. Verify the build completed successfully
2. Check that the file was created in the `release/` directory
3. Verify GITHUB_TOKEN has the correct permissions

## Additional Notes

- Remember: You **cannot** push tags using Copilot coding agent. Tags must be pushed manually by you.
- The workflows require submodules to be initialized (`submodules: recursive` in workflow)
- You can force a rebuild by deleting and recreating the tag
- Manual file uploads to releases are not needed - the workflows handle everything automatically
